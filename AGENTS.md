# DaaS Web Development
- This branch is dedicated to the DaaS web service.
- Read `README.md`, `daas-web/README.md`, and `daas-web/UPGRADE.md` before changing deployment or dependencies.
- Keep upstream source snapshots under `packages/{agent,ai,telemetry}` unchanged unless explicitly upgrading.
- These snapshots are not npm workspaces. Do not run their independent package build/install scripts.
- Keep direct dependency versions exact. Preserve retained lockfile versions, URLs, and integrity values.
- Do not restore CLI, TUI, remote bridge, online extension installation, or automatic directory discovery.
- Business tools live under `daas-web/.daas/extensions`; register explicitly in `.daas/index.ts`.
- Run `npm run check`, app tests, and (with dependencies available) the upstream contract and release smoke.
- Never use real company credentials or endpoints for tests. Never log secrets.
- Do not force-push or modify company-deepseek. Commit only changes authorized by the user.
